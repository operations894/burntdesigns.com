Burnt Designs Website Starter

How to use:
1. Open index.html in any web browser.
2. Edit business email in index.html: replace orders@gotwood.example with your real email.
3. Upload all files to a web host like GoDaddy, Netlify, Vercel, or Shopify custom page.

Included features:
- Homepage for Burnt Designs
- Custom natural edge slab/table sections
- Driveway entry sign section
- Live customer picture previewer
- Wood material selector
- Epoxy/accent color selector
- Custom sign/table text and font preview
- Checkout-style custom order form using mailto

To take real online payments:
Connect the form to Shopify, Square, Stripe, WooCommerce, or a custom backend.
